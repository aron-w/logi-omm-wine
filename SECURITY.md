# Security

OMME is a wrapper around Wine and proprietary vendor software. It does not
modify mouse firmware directly; Logitech Onboard Memory Manager performs device
communication through Wine.

Please report security issues privately before opening a public issue. Until a
dedicated contact is published, use the repository owner's preferred private
contact channel.

Do not include proprietary Logitech binaries, personal device identifiers, or
full Wine prefixes in public reports.
